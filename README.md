# Порівняльний аналіз методів машинного навчання для діагностики серцево-судинних захворювань

Курсова робота з дисципліни **«Обробка надвеликих масивів даних»**.

## Мета роботи

Дослідити, реалізувати та провести порівняльний аналіз різних методів машинного навчання для задачі бінарної класифікації ризику наявності серцево-судинних захворювань.

## Набір даних

У роботі використано набір даних **UCI Heart Disease**.

Набір даних містить:

- 303 записи;
- 13 вхідних ознак;
- цільову змінну, що характеризує наявність або відсутність серцевого захворювання.

Початкову цільову змінну було перетворено на бінарний формат:

- `0` — захворювання відсутнє;
- `1` — захворювання присутнє.

Основні ознаки набору даних:

- `age` — вік пацієнта;
- `sex` — стать;
- `cp` — тип болю у грудях;
- `trestbps` — артеріальний тиск у стані спокою;
- `chol` — рівень холестерину;
- `fbs` — рівень цукру натще;
- `restecg` — результат ЕКГ у стані спокою;
- `thalach` — максимальна частота серцевих скорочень;
- `exang` — наявність стенокардії при фізичному навантаженні;
- `oldpeak` — депресія сегмента ST;
- `slope` — нахил сегмента ST;
- `ca` — кількість великих судин, забарвлених під час флюороскопії;
- `thal` — результат відповідного клінічного дослідження.

1. Завантаження та початковий аналіз набору даних UCI Heart Disease.

7. Аналіз можливих аномальних значень.
8. Аналіз розподілу основних клінічних показників.
9. Аналіз кореляції ознак із цільовою змінною.
10. Розділення набору даних на тренувальну та тестову вибірки.
11. Обробку пропущених значень.

## Використані моделі

Для порівняльного аналізу було реалізовано три алгоритми класифікації:

- **Logistic Regression**;
- **Support Vector Machine (SVM)**;
- **Random Forest**.

Для Logistic Regression та SVM числові ознаки масштабувалися за допомогою `StandardScaler`.

Для Random Forest масштабування не застосовувалося, оскільки алгоритми на основі дерев рішень не є чутливими до масштабу ознак.

## Метрики оцінювання

Якість моделей оцінювалася за такими метриками:

- **Accuracy**;
- **Precision**;
- **Recall**;
- **F1-Score**;
- **ROC-AUC**.

Окрему увагу було приділено метриці **Recall** та кількості **False Negative**, оскільки в медичній задачі особливо небезпечною є ситуація, коли модель не виявляє захворювання у пацієнта, в якого воно фактично присутнє.

## Результати

| Модель | Accuracy | Precision | Recall | F1-Score | ROC-AUC |
|---|---:|---:|---:|---:|---:|
| Logistic Regression | 0.8852 | 0.8387 | 0.9286 | 0.8814 | 0.9665 |
| SVM | 0.8852 | 0.8387 | 0.9286 | 0.8814 | 0.9643 |
| Random Forest | 0.8689 | 0.8125 | 0.9286 | 0.8667 | 0.9437 |

Усі три моделі отримали:

- `Recall = 0.9286`;
- `False Negative = 2`.

Logistic Regression та SVM показали однакові значення Accuracy, Precision, Recall та F1-Score.

Найвище значення ROC-AUC отримала **Logistic Regression — 0.9665**. Саме тому за сукупністю показників її було обрано як найкращу модель.

## Найкраща модель

## Практична реалізація

Для демонстрації практичного застосування найкращої моделі реалізовано консольний застосунок `app.py`.

Застосунок дозволяє користувачеві ввести 13 клінічних показників пацієнта, після чого завантажена модель формує прогноз:

- **низький ризик серцевого захворювання**;
- **високий ризик серцевого захворювання**.

Також програма відображає оцінену моделлю ймовірність наявності захворювання.

## Висновок

У межах курсової роботи було реалізовано повний цикл побудови системи машинного навчання для задачі бінарної класифікації ризику серцевого захворювання: від аналізу та підготовки даних до навчання, порівняння, вибору та практичного використання найкращої моделі.

Було досліджено три різні алгоритми класифікації — Logistic Regression, SVM та Random Forest. За сукупністю отриманих результатів найкращою було обрано Logistic Regression, яка продемонструвала Accuracy близько 88,52%, Recall близько 92,86% та ROC-AUC близько 0,9665.

Отриману модель було збережено та інтегровано в окремий консольний застосунок для демонстрації її практичного використання.

> **Примітка:** результат роботи моделі є демонстрацією застосування методів машинного навчання та не є медичним діагнозом.
